# ArrowLab Working Authority

When the user requests or approves an ArrowLab firmware, code, configuration, or documentation change, that authorization includes making the required task-specific edits and committing and pushing them to the active agent/* feature branch without requesting separate confirmation.

Prefer surgical edits that preserve established behavior and architecture. Rewrite files or substantial components only when necessary for the approved task or when explicitly requested.

Before publishing, inspect the affected files and changes. Do not include unrelated modifications.

Do not push directly to main, merge pull requests, force-push, delete branches, rewrite published history, or make unrelated repository changes without explicit user approval.
